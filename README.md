# StudentHub — Student Registration System

A responsive student registration and record-management web app built with **HTML, CSS and vanilla JavaScript**.

## Features
- Add student records (name, email, age and course)
- View all saved student records
- Search by student name, email or course
- Edit existing student details
- Delete records with a confirmation prompt
- Prevent duplicate email addresses
- Display total students and unique courses
- Save records in browser Local Storage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser. You can also use the VS Code Live Server extension.

## Technologies
- HTML5 — page structure and form
- CSS3 — styling and responsive layout
- JavaScript — form handling, search, CRUD operations and Local Storage

## Important note
This is a **front-end learning project**. It stores records in the browser's Local Storage; it does not use a backend server or a shared database. Records are local to the browser/device where they were entered.

## What I learned

- Selecting and updating page elements with the DOM
- Handling user events
- Using arrays and array methods
- Implementing Create, Read, Update and Delete (CRUD) operations
- Saving and retrieving data with Local Storage
- Building a responsive user interface
